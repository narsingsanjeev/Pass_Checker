# Pass_Checker
A Python-based cybersecurity tool that analyzes password is strong and securely checks if the password has been compromised in real-world data breaches.
Features:
Strong Password:Repeatedly asks users enter valid password until all conditions satisfied(length,uppercase,lowercase,special charcter,number) using re module in python
Privacy:After Validation Checks current Password with matched in real-world data using hashlib and requests module using HaveIbeenPwned
